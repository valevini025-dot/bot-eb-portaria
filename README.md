# bot-eb-portaria
🤖 Bot oficial de Portaria para servidores Discord de EB (Exército Brasileiro).  Sistema automatizado de registro de entradas, com logs personalizados, identificação de membros, avatar, data e horário. Inclui comando /teste-entrada e configurações de acesso restrito.  Desenvolvido em Python com foco em organização, segurança e praticidade.
